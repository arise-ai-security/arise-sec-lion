System Overview

A self-healing multi-agent platform for reproducing & fixing real CVEs

Arise compares a flat N1 baseline with adaptive and role-fused agent teams on SEC-bench CVEs. LLM workers build evidence and code; trusted host procedures execute fixed checks; a separate evaluator decides success from fresh replay, provenance, and blinded semantic review.

event-sourced · 42 event types hexagonal / ports-and-adapters Docker-out-of-Docker CVE runtime deterministic procedure tier

01  /  What it is

A benchmark harness for agent topologies on security tasks

SEC-bench ships hundreds of real CVEs, each as a Docker image with the vulnerable source, a build script, and a known sanitizer crash. Arise points a configurable team of LLM agents at each CVE and asks them to Build → Exploit → Fix → Report inside the container. Because everything the agents do is recorded as an immutable event stream, the same run can be replayed, cost-accounted, and independently judged — the platform's job is to make agent behavior trustworthy and comparable, not just to pass the benchmark.

02 / Treatments

N1 baseline, B4 adaptive, B3 role-fused

The next confirmatory study compares N1 with B4. B3 remains a development ablation. It is a manager-plus-specialization composite, because removing managers also fuses role prompts and reallocates model tokens; it cannot identify a pure manager effect.

03  /  System architecture

Hexagonal: a pure core, adapters at the edge

The domain core depends only on the standard library and its own Protocol ports — it never imports infrastructure (a pre-commit hook enforces this). Everything concrete (Postgres, LLM providers, the OpenHands worker, the SEC-bench container runtime) is an adapter injected at startup. bootstrap/composition.py is the only file allowed to reach across the boundary into plugins/.

04  /  Code structure

How the architecture maps to directories

Each architectural layer is one top-level directory with a strict import rule. The extension points are narrow: a new capability is an adapter in infrastructure/, a new domain is a plugin, and a new prompt is a Jinja2 template — the core rarely changes.

05 / Adaptive B4

Compact first; specialists only after evidence of failure

Trusted host policy creates the four phase controllers and their compact role children. The managers do not freely invent the initial route. Required dependencies make each phase wait for its predecessor; a failed required child prevents false phase completion.

07 / Resilience

Self-healing: a crash becomes context, not a dead end

When a worker crashes it usually carries no retry context. Arise fixes that deterministically — no LLM involved. The failure is distilled into a bounded digest and injected into the next attempt; if every sibling worker still fails, the parent doesn't give up — it re-decomposes, informed by exactly why the last attempt failed.

08 / Deterministic procedures

A deterministic tier for tasks that don't need an LLM

Four roles have frozen command and transformation contracts. With procedural_dispatch enabled, they run host-side with zero LLM turns. Here, “host” means the trusted Arise process—not a human operator. Arise captures command evidence and computes the verdict; an agent-written VERDICT: PASS is never authoritative.

09 / Success and judges

Mechanical truth first; semantic judgment stays separate

The target evaluator has no human queue or override. It seals objective execution facts before asking models about root-cause and patch semantics. Judges cannot rescue a timeout, wrong crash, sanitizer suppression, failed build, or regression.

11 / Reference

Event families & glossary

Event stream 42 frozen types · EVENT_TYPE_REGISTRY · two aggregates

lifecycleAgentCreated, TaskAssigned, ChildSpawned, ChildCompleted, ChildFailed, WorkCompleted, WorkFailed — the agent tree.
resilienceRetryScheduled, FailureDigestRecorded, RedecompositionTriggered — the self-healing loop.
procedureProcedureExecutionStarted, ProcedureExecutionFinished (host ProcedureEvidence) — the deterministic tier.
verifyVerificationPassed, VerificationFailed (structural / deterministic / execution / judge).
sharedSharedContextCreated, ArtifactStored, DecisionRecorded — the 3 SharedStore events.
AgentSession
Primary event-sourced aggregate; 39 of 42 events replay into it. Never mutated directly.
SharedStore
Second aggregate (artifacts + decisions), sharing the events table via a uuid5 id.
failure_digest
Deterministic, LLM-free summary of a failed attempt, injected into the retry prompt.
Re-decomposition
A parent re-plans (bounded by max_redecompositions) informed by failure_history.
Procedural dispatch
Flag-gated tier running registry-matched tasks host-side with zero LLM turns.
ProcedureEvidence
argv · exit_code · output_sha256 · excerpt per command — captured by the host, unforgeable.
DooD
Docker-out-of-Docker: the orchestrator launches each CVE container on the host's Docker daemon.
Crash signature
(sanitizer_class, access_type, top_frame) — matched against the CVE oracle to decide a verdict.
