System Overview

A self-healing multi-agent platform for reproducing & fixing real CVEs

Arise compares a naive flat N1 control with B4's adaptive hierarchy on SEC-bench CVEs. Both solve the same task and face the same external success criteria. B4 additionally receives Host-controlled in-run procedures; N1 receives no Host mechanical assistance. B3 is the Manager-layer ablation.

01  /  What it is

A benchmark harness for agent topologies on security tasks

SEC-bench ships hundreds of real CVEs, each as a Docker image with the vulnerable source, a build script, and a known sanitizer crash. Arise points a configurable team of LLM agents at each CVE and asks them to Build → Exploit → Fix → Report inside the container. Because everything the agents do is recorded as an immutable event stream, the same run can be replayed, cost-accounted, and independently judged — the platform's job is to make agent behavior trustworthy and comparable, not just to pass the benchmark.

02 / Experiment

One task contract, two solving systems, one external evaluator

The confirmatory comparison is N1 versus B4. N1 is a deliberately naive OpenHands control: one session, subagents disabled, and procedural dispatch explicitly off. B4 is the complete adaptive treatment. Both must produce the same evidence and are scored by the same post-run evaluator. The estimand is therefore the effect of the complete B4 system, not hierarchy in isolation.

03  /  System architecture

Hexagonal: domain logic behind ports, adapters at the edge

The domain core owns orchestration logic and its Protocol ports. It uses declared libraries such as Pydantic and Jinja2, but never imports infrastructure/ (a pre-commit hook enforces this). Concrete Postgres, LLM, worker, and container adapters are injected at startup. bootstrap/composition.py is the only file allowed to reach across the boundary into plugins/.

04  /  Code structure

How the architecture maps to directories

Each architectural layer is one top-level directory with a strict import rule. The extension points are narrow: a new capability is an adapter in infrastructure/, a new domain is a plugin, and a new prompt is a Jinja2 template — the core rarely changes.

05 / Adaptive B4

Compact first; specialists only after evidence of failure

Trusted host policy deterministically creates the four-phase DAG and compact role children. Managers do not choose the initial route. Only after a required failure does the phase Manager use the existing LLM decomposition path to propose same-phase roles and failure-specific instructions.

07 / Resilience

Self-healing: a crash becomes context, not a dead end

When a worker crashes it usually carries no retry context. Arise fixes that deterministically — no LLM involved. The failure is distilled into a bounded digest and injected into the next attempt. If required workers still fail, only their Manager may re-decompose from the recorded failure evidence; non-Manager parents fail upward.

08 / B4 treatment mechanics

Deterministic Host gates with one bounded repair

This section applies to B3/B4 when procedural_dispatch is enabled. Four roles have frozen command and transformation contracts, and each initial Host attempt uses zero LLM turns. An initial failure permits exactly one LLM-backed repair and, if that repair completes, exactly one Host recheck. N1 pins procedural_dispatch=false, follows the ordinary OpenHands path, and cannot receive procedure evidence, Host failure feedback, patch rendering, or a Host recheck. “Host” means the orchestrator process, not a human; fresh external replay remains the confirmatory authority.

The agent-authored repro.sh is parsed, not executed. Its final exec "$BIN" accepts only inert arguments with one $POC, or a final stdin redirect. Valid examples are OpenEXR exec "$BIN" -v "$POC" /dev/null and FAAD2 exec "$BIN" "$POC" -o /dev/null; shell control, substitution, wrappers, pipes, setup, and other redirection fail closed.

09 / Success and judges

One post-run success contract for both arms

Evaluation begins only after the solver run is closed and sends no repair feedback to N1 or B4. The evaluator seals objective execution facts before asking models about root-cause and patch semantics. Judges cannot rescue a timeout, wrong crash, sanitizer suppression, failed build, or regression.

Event families & glossary

lifecycleAgentCreated, TaskAssigned, ChildSpawned, ChildCompleted, ChildFailed, WorkCompleted, WorkFailed — the agent tree.

AgentSession
Primary event-sourced aggregate; 39 of 42 events replay into it. Never mutated directly.
SharedStore
Second aggregate (artifacts + decisions), sharing the events table via a uuid5 id.
failure_digest
Deterministic, LLM-free summary of a failed attempt, injected into the retry prompt.
Re-decomposition
A Manager re-plans (bounded by max_redecompositions) from failure_history; non-Manager parents fail upward.
Procedural dispatch
Flag-gated tier whose Host attempts use zero LLM turns; initial failure permits one agentic repair and, if it completes, one Host recheck.
ProcedureEvidence
argv · exit_code · output_sha256 · excerpt per command — Host-computed and not directly agent-authored; still in-run evidence from the shared worker container.
DooD
Docker-out-of-Docker: the orchestrator launches each CVE container on the host's Docker daemon.
Crash signature
(sanitizer_class, access_type, top_frame) — matched against the CVE oracle to decide a verdict.
